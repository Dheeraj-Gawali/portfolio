## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Dheeraj-Gawali/portfolio.git
```

Navigate to the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
ng serve
```

Open

```text
http://localhost:4200
```

## 🚀 Deployment

Build for GitHub Pages

```bash
npm run build:gh
```

Deploy

```bash
npm run deploy
```
